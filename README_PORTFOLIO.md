# D3 Portfolio Website

Static portfolio site for Poojari Venkata Shreesh, positioned around D3.js, interactive data storytelling, graph analytics, and AI/data systems.

## What It Includes

- D3 force-directed hero network
- D3 project bubble chart with category filters
- D3 radar chart for visualization/system strengths
- D3 career timeline
- Animated counters from resume/project metrics
- Responsive desktop and mobile layout
- Local resume asset at `assets/Poojari-Venkata-Shreesh-Resume.pdf`

## Run Locally

```bash
cd portfolio
python -m http.server 8000
```

Open `http://localhost:8000`.
