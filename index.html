Inside TravelMate Problem, decisions & outcome+

The problem

Travel requests are rarely complete.

A destination alone is not enough to produce a practical trip. The system needs to interpret preferences, identify missing constraints, and account for routes without making the conversation feel like a form.

The decisions

Separate interpretation from control.

  • Use Gemini for state extraction and explanations, with explicit completeness and feasibility gates.
  • Keep the Next.js UI connected through a same-origin API proxy and a stable response mapping layer.
  • Handle incomplete sessions and degraded AI/API paths with follow-up questions and fallback responses.

The product flow

Ask. Clarify. Plan. Refine.

Type or speak a request → resolve missing details → discover places and routes → review itinerary cards → refine preferences in chat.

Result: a working conversational planning flow spanning the interface, orchestration, voice, and mapping services.

The tradeoff

A prototype with clear boundaries.

Session memory and response caching are ephemeral. Durable storage would be the next step for conversation recovery across service restarts. Existing tests cover normalization, feasibility, memory, and itinerary optimization.

Inside Fashion AI+

Problem & flow

Recommendations need wardrobe context.

Sign in → upload a garment → review structured analysis → save it to your wardrobe → ask for styling or try an outfit. The product connects visual understanding with the items a user actually owns.

Architecture

Identity follows every request.

A browser client calls a Node.js/Express API. Cognito verifies access tokens, Gemini handles multimodal tasks, DynamoDB scopes records by user, and S3 stores private images. CDK defines containerized infrastructure for dev, staging, and production.

Engineering decisions

  • Resize image inputs and validate structured model responses before persistence.
  • Use temporary signed URLs for private images and clean up orphaned S3 uploads if database writes fail.
  • Bound chat and wardrobe context; validate uploads and rate-limit API requests.

Outcome

A complete wardrobe and styling implementation, from authentication and image ingestion to recommendations and virtual try-on. Repeatable AWS infrastructure is defined in code; deployment scale and adoption are not measured.

Inside Accio+

Problem & flow

A useful answer needs evidence.

PDFs scatter facts across pages and layouts. Accio extracts text and layout information, builds a searchable knowledge graph, and lets a user ask a question and inspect the source behind the answer.

Architecture & decisions

  • Keep page and bounding-box metadata through extraction so citations can point back to the document.
  • Combine semantic retrieval, full-text search, and graph traversal for complementary evidence.
  • Use local sentence-transformer embeddings; use Gemini for triplet extraction and answer generation.
  • Serve query results through FastAPI to a Streamlit interface with citation highlights.

Outcome

Grounded document Q&A with inspectable citations. Project evaluation reported in my résumé: 77.5% entity accuracy and 0.76–0.82 NDCG@5.
